# 论文视觉统筹

让每张图承担明确的论证任务，让全篇图表在科学含义、视觉语言和最终排版上相互配合。用户要求升级成稿时，完成可编辑图源、论文接入和成稿检查，不能只提交配色建议或规划表。

## 范围与工作方式

- **全篇升级**：从摘要与结论中的主张出发，盘点正文图、表、引用和图源，决定保留、修改、合并、移位或补充什么。图的数量由论证缺口与篇幅决定，不设固定新增数量。
- **局部设计**：读取目标图前后的论述、图注、数据来源，以及全篇已有样式和相关图。直接完成局部任务，不强制重做全篇，也不要求额外建设一套规划文档。
- **仅规划或审阅**：尊重用户所限范围，交付可执行的图谱与问题清单，不擅自改写论文。

优先沿用项目已有的图源形式、生成程序、排版引擎与可用环境。用户已授权的可逆制作与验证直接推进；仅在缺失的原始材料或关键语义影响结论时说明具体缺口，并继续独立可完成的部分。缺数据时不能把效果图当成研究结果。

## 1. 从论文主张建立图谱

读取摘要、章节结构、核心结论、方法与验证部分；同时找到现有插图、图注、引用、图表生成代码和结果来源。必要时查看当前编译稿，避免只凭源文件判断字号与位置。

对每个核心主张问：读者需要看见什么关系、步骤、比较或证据才能理解它？区分：

- **问题与模型关系图**解释各部分如何相依或并列；连线不能虚构计算先后关系。
- **模型或几何示意图**解释对象、变量、边界、假设与耦合；示意形状不是测量结果。
- **算法流程图**解释输入、计算、分支、迭代、停止条件与输出；按现有方法或代码确认分支，不画一条省略关键判据的装饰流水线。
- **数据与结果图**展示观测、计算、比较或不确定性；图中每条曲线、每个区域都有可追溯的数值或数学来源。
- **验证图**回答某项数值或统计结论有何支持，不把局部检验画成整个模型的物理真实性证明。

全篇任务先形成一份紧凑图谱，复用项目已有记录位置。每图至少记录：`图标识 / 支撑主张 / 图的角色 / 证据与图源 / 操作 / 所在段落 / 成品尺寸 / 验收重点`。同时检查重复：精确数值表已经回答的问题，不为增加图量再做一张相同柱状图。

## 2. 固定科学含义，再设计外观

制作前核对来源、单位、适用区间、数据精度与变换。贯穿图形、图例和图注区分：

- 实测观测、模型计算、假设延续与纯示意；历史结果与本次新计算。
- 离散采样与连续解、数值插值与真实观测；显示精度与求解精度。
- 零值、缺失值、域外位置、删失或未执行的情形。
- 误差估计、敏感性情景、置信区间和参考阈值；不能互换标签。

数据图读取现有真实附件、结果文件或可复现的模型输出，不为画得平滑、美观或显著而补造、篡改、选择性隐藏数据。仅有舍入后的采样结果时，保持这一精度和采样身份；不能反推成高精度连续轨迹。现有证据不足以支撑某图时，说明缺少的来源，完成不受影响的图，不制造占位结果混入成稿。

视觉任务默认保持模型、参数、求解判据和结论不变。若发现图与证据冲突，修正可由现有证据明确判断的图形或表述，并报告影响；需要新增科学分析的部分按用户授权范围处理。

## 3. 统一视觉语言与最终尺寸

全篇升级时，在重画之前选定共用的语义色、字体、线宽、标记、面板标识、图例方式与留白。局部任务沿用这些已有约定，仅调整目标图，不因统一风格而修改无关图或共享样式。以用户偏好、现有论文风格和目标模板为依据；不能让每张图各自形成一套互相冲突的编码。

同一实体或情景跨图尽量同色、同线型；颜色同时配合标记、线型、标签或分面。连续数值、正负差异与类别分别使用合适的色标，不用艳丽程度表达未定义的“重要性”。图注交代阅读方法、条件和必要限制，正文负责解释结论，避免在图框里堆放整段方法文字。

按论文实际插入宽度和可用高度设计，而非先画大图再整体缩小。核算最终字号、线宽、色标及图例可读性；中文、拉丁字母和数学符号均需在交付环境正确渲染。具体布局取舍、可覆盖的“偏活泼科研期刊”风格和尺寸计算见 [references/visual-design.md](references/visual-design.md)，在确定样式或处理复杂图时读取。

## 4. 选择可维护的实现并接入正文

| 内容 | 优先实现 | 保留的交付物 |
| --- | --- | --- |
| 关系、算法、几何与模型示意 | 项目已有的 TikZ、SVG、DrawIO 或同类可编辑向量；根据公式、几何和后续编辑需求选择 | 可编辑源文件及论文可用的矢量导出 |
| 曲线、统计图、场分布与数值验证 | 项目已有的数据处理/绘图程序，如 Python、R 或其他可用科学绘图工具 | 图源程序、真实数据或明确来源、可重建的论文图 |
| 原始照片、显微图等栅格材料 | 保留原图与必要的有记录裁切/标注 | 原始来源、处理方式与成品 |

PDF 或 SVG 扩展名不保证内容为向量：检查图是否只封装了一张位图。非数据方法图通常无需图像生成服务；复杂场图可仅将数据层栅格化，保留文字、坐标、边界与标注为向量。不得把矢量化描摹误称为恢复原始数值信息。

优先修改现有生成入口和局部样式，不改无关项目配置。仅在必要时补充依赖，避免为了统一风格强制更换整个绘图栈。将成图置于所支撑论点的首次相关论述附近，更新图注、标识和交叉引用；保留中文建模论文的题定输出表与必要问题顺序。样式变动影响页数时，先调整布局、冗余与图文位置，不靠难以阅读的缩放隐藏问题。

## 5. 编译、逐页检查并交付

使用项目真实排版入口生成完整论文，完成引用解析所需的构建轮次；不得把单张图导出成功当作论文完成。

- 全篇任务检查成稿所有页面，包括图页和因浮动、分页而变化的相邻正文页；局部任务仍编译完整论文，重点检查修改页、连带分页和全篇引用。
- 在成品尺寸下逐页查看：字号、字体缺失、文字与箭头重叠、裁切、色标/单位、图注、页边界、分页空白及与正文的距离。缩略图总览可辅助发现布局问题，不能代替细节检查。
- 回核图中关键值、阈值、曲线标识、留空区域与证据源。比较可比面板的坐标与色标，确认视觉优化没有改变科学含义。
- 查编译日志中的缺失资源、未解析引用和实际溢出；修复影响交付的问题，再检查受影响页面。不能静默过滤告警后声称版式已验证。

交付与范围相称的成品：更新后的论文和所涉及图类的可编辑图源；涉及数据图时提供可复现的生成入口；全篇任务附简短图谱/变更与检查记录。说明仍缺失的证据或环境限制，不把未完成的编译、渲染或数值复核写为通过。没有目标期刊时采用清晰的一般科研版式；指定期刊时核实其官方要求，不将某套字体、配色或 DPI 自动等同于期刊合规。
